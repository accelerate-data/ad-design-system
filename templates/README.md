# Templates

Reusable presentation and document templates. These assets live in the source
repository; they are not bundled with the design-system plugin.

| File | Use |
| --- | --- |
| [Accelerate-Data-Document-Template.dotx](Accelerate-Data-Document-Template.dotx) | Word template for Accelerate Data company documents, proposals, and reports. |
| [Accelerate-Data-Document-Template.docx](Accelerate-Data-Document-Template.docx) | Editable document copy for previewing or starting with Save As. |

## Start a Word document

1. Open the `.dotx` in desktop Microsoft Word to create a new document from it.
2. Replace the bracketed placeholders on the cover and in the body, header, and footer.
3. Use Word's Styles pane to apply headings, body text, lists, callouts, and captions.
4. Copy or remove sample sections and table rows as needed.
5. Save the new document as `.docx`. Update fields before exporting or printing so page counts are current.

The sample has three A4 pages: a cover, an executive summary, and a detail page
with a table, actions, and references. Content uses native Word paragraphs,
styles, lists, and tables. Page numbers are fields. The cover has its own footer
and no running header.

## Formatting

The template follows the corporate Accelerate Data design system:

- Geist body text, Geist SemiBold headings, and Geist Mono metadata and technical values.
- Navy headings, Smoke body text, Pacific rules, and Powder callouts on white pages.
- An embedded corporate wordmark from `logo/product/ui/logo-dark-h64@2x.png`.
- A corporate Office theme for new text, tables, and other themed content.
- Full embedded font files, converted from the repository's WOFF2 assets, so the fonts include characters beyond the sample text.

| Word style | Purpose |
| --- | --- |
| Title / Subtitle | Cover title and supporting line |
| Heading 1–3 | Navigable section hierarchy |
| Normal | Body text at 10.5 pt |
| List Bullet / List Number | Native bulleted and numbered lists |
| Caption | Table, figure, and source descriptions |
| AD label | Small section and metadata labels |
| AD metadata | Dates, versions, and identifiers |
| AD callout | A key message with a Powder background |
| AD code | Technical values on a Pearl background |
| AD table | Reusable table style with a Navy header row |

Font embedding support varies between applications. Use desktop Word for the
template workflow. If an editor substitutes fonts, install Geist and Geist Mono
locally. Long replacement text can change pagination; review the document before
sharing it. The editable copy and template have identical content and styles.

## Rebuild

From the repository root:

```bash
uv run scripts/generate_word_template.py
```

The script pins its Python dependencies and reads the corporate color tokens,
font files, and logo from this repository. It overwrites both generated Word
files. Keep template changes in the script; edits made only in Word will be lost
on the next rebuild. The PowerPoint file is not generated by this script.
